# ITT Landing — תבנית וורדפרס

תבנית עצמאית (standalone theme) המשחזרת את העיצוב של דף הנחיתה להכשרת
**ITT Leader · מחזור 20** (מרכז ישיר), לפי חבילת ההנדאוף `design_handoff_itt_landing`
ולפי **תקן הפיתוח של Multi Digital**.

- ללא page builder, ללא ACF, ללא jQuery, ללא ספריות צד ג'.
- כל התוכן יושב **בתוך העמודים עצמם** (post meta של העמוד) ונערך בעורך העמוד.
- PHP 8.3+, `declare(strict_types=1)`, WordPress Coding Standards.

---

## התקנה

1. להעלות את התיקייה `itt-landing` אל `wp-content/themes/`.
2. **מראה → ערכות עיצוב → הפעלה.**
3. בהפעלה נוצרים אוטומטית שלושה עמודים, כשכל התוכן מהעיצוב כבר בתוכם:

   | עמוד | כתובת | תבנית |
   |---|---|---|
   | הכשרת ITT Leader · מחזור 20 | `/itt-leader/` | ITT · דף נחיתה |
   | תודה — הפרטים התקבלו | `/itt-leader-toda/` | ITT · עמוד תודה |
   | הצהרת נגישות | `/hatsharat-negishut/` | ברירת מחדל |

4. להעלות את קובצי הגופן Ploni — ראו `assets/fonts/README.md`. **בלי זה העמוד
   עובד אבל אינו זהה לעיצוב.**
5. **כלים → עמודי ITT** — יצירת עמוד שנמחק בטעות, או איפוס עמוד לתוכן המקורי.

## עריכת התוכן

נכנסים לעמוד בעורך העמודים. מתחת לעורך יש **תיבה לכל סקשן בעיצוב**, לפי הסדר:
`01 · הירו`, `02 · ניתוב מהיר`, `03 · הכאב` וכן הלאה עד `16 · סגירה וטופס`,
ובנוסף `כותרת עליונה, פוטר וסרגל צף`.

### רשימות ללא הגבלה

כל רשימה בעמוד היא **חוזרת וללא תקרה** — אפשר להוסיף ולהסיר שורות כרצונכם:
סרטוני המלצות, תמונות גלריה, עדויות כתובות, שיעורים בשני הסמסטרים, בונוסים,
שאלות ותשובות, ציטוטים מתחלפים, כרטיסי התאמה ותגיות. לחצן **"+ הוספת שורה"**
בתחתית כל רשימה; **"מחיקה"** בראש כל שורה.

### תמונות ווידאו

- **תמונה** — בורר ספריית המדיה הרגיל של וורדפרס. שדה ריק = התמונה שמצורפת
  לתבנית (`assets/img/`).
- **וידאו** — שתי דרכים, לבחירתכם:
  1. **קובץ וידאו מהמדיה** — מעלים mp4/webm ישירות לספריית המדיה ובוחרים.
  2. **קישור** — YouTube או Vimeo.

  אם הועלה קובץ, הוא קודם לקישור. בשני המקרים **שום דבר לא נטען לפני שהגולשת
  לוחצת play** — מוצגת תמונת פתיח בלבד. זה שומר על מהירות הטעינה ועל הפרטיות.

### הדגשות בתוך טקסט

בשדות כותרת מסומנים אפשר להשתמש בתגיות הבאות (לא HTML — רק אלה):

| תגית | מה זה עושה |
|---|---|
| `[hl:gold]מילה[/hl]` | קו טוש נמשח מימין לשמאל. גם `cyan` ו-`orange` |
| `[pop]מילה[/pop]` | ביטוי שקופץ פנימה בגלילה |
| `[blink]מילה[/blink]` | החלפת צבע מחזורית |
| `[value]4,600 ₪[/value]` | קפיצה + הבהוב, לסכומים |
| `[gold]טקסט[/gold]` | טקסט זהב קבוע |
| `[count:26]` | ספירה מ-0 עד 26 |
| `[count:4600,comma]` | ספירה עם פסיק (4,600) |

כל טקסט אחר עובר escaping מלא — אי אפשר להזריק HTML דרך שדה תוכן.

## הפניות מהטופס

טופס "בדיקת התאמה" שולח ל-REST endpoint (`itt/v1/lead`) ולא לעמוד עצמו, כדי
שהעמוד יישאר **cacheable במלואו** מול LiteSpeed ו-Cloudflare — אין nonce מודפס
ב-HTML; הדפדפן מושך nonce טרי מ-endpoint שאינו נשמר במטמון רגע לפני השליחה.

- הפניות נשמרות תחת **פניות ITT** בתפריט הניהול (`private`, לא נגישות לציבור).
- נשלח מייל התראה לכתובת מנהל האתר. לשינוי: פילטר `itt_lead_notification_email`.
- הגנות: honeypot, בדיקת זמן מילוי, Rate limiting (5 פניות לשעה לכל IP,
  ה-IP עובר hash לפני שהוא נכנס למפתח transient), ולידציה מלאה בצד שרת.
- אחרי שליחה מוצלחת — הפניה לעמוד התודה.

## נגישות (WCAG 2.2 AA + ת"י 5568)

**שלושת העמודים עוברים סריקת axe-core ללא הפרות** (0 violations), בבדיקה
אוטומטית מול Chromium בגודל דסקטופ.

מה נבנה פנימה:

- HTML5 סמנטי, `H1` יחיד, היררכיית כותרות רציפה, קישור "דילוג לתוכן".
- הפעלה מלאה במקלדת: סימון פוקוס גלוי, סדר Tab לוגי, ללא מלכודות מקלדת.
- טאבים של הסילבוס: `role="tablist"` מלא עם ניווט בחיצים (**ב-RTL: חץ שמאלה
  מתקדם**), `Home` / `End`.
- אקורדיונים בנויים על `<details>` נייטיבי — עובדים גם בלי JavaScript;
  הסקריפט רק מוסיף את "אחד פתוח בכל רגע" שבעיצוב.
- ציטוטים מתחלפים בתוך `aria-live="polite"`, נעצרים בריחוף ובפוקוס, ויש
  כפתורי הקודם/הבא.
- `prefers-reduced-motion` מכובד במלואו, **וגם לחצן "עצירת אנימציות בעמוד"**
  בפוטר (נדרש ב-WCAG 2.2.2 בגלל ה-CTA המהבהב). הבחירה נשמרת ב-localStorage.
- תוויות `<label>` אמיתיות בכל שדה טופס, הודעות שגיאה מקושרות ב-`aria-describedby`
  ומוכרזות ב-`role="alert"`, `aria-invalid` על שדה שגוי.
- כל תמונה עם `alt` בעברית; אלמנטים דקורטיביים (ציפורים, קווי הפרדה, ✓/✕,
  סימני `+`/`=`) מוסתרים מקוראי מסך.
- וידאו לא נטען ולא מתנגן אוטומטית; קובץ מהמדיה מקבל פקדים נייטיביים.

### סטיות מכוונות מקובץ העיצוב

התקן קובע ש**לעולם לא מקריבים נגישות למען אפקט ויזואלי**. שבעה ערכי צבע
מקוריים נכשלו ביחס הניגודיות הנדרש והועמקו. הגוון והקצב נשמרו:

| # | מקור | שונה ל- | איפה | למה |
|---|---|---|---|---|

| 2 | `#16B4E8` | `#0E5E80` | טקסט `valueBlink` | 2.3:1 → 6.0:1 |
| 3 | `#16B4E8` | `#0E5E80` | רקע `ctaBlink` | 2.4:1 → 5.6:1 |
| 4 | `#F2662A` | `#A6541A` | הדגשות `[pop]` על רקע בהיר | 2.9:1 → 5.1:1 |
| 5 | `#F2662A` | `#C8511A` | תגית כרטיס יכולות כתום | 3.1:1 → 5.4:1 |

כדי להיכנס להגדרת "טקסט גדול" (סף 3:1) — הצבע נשאר בדיוק כמו בעיצוב.

**הצהרת הנגישות** נוצרת אוטומטית עם החלקים הטכניים מלאים. שלושה סעיפים
מסומנים `[יש להשלים: ...]` — שם רכז/ת הנגישות, הסדרי הנגישות הפיזיים ותאריך
הבדיקה. **חובה למלא לפני עלייה לאוויר.**

## ביצועים

- **טעינה מותנית מלאה**: עמוד שאינו אחת משתי תבניות ה-ITT לא טוען מהן שום CSS
  או JS. בתבניות עצמן `wp-block-library` ו-`global-styles` מוסרים.
- שני קובצי CSS ושני קובצי JS לכל היותר בעמוד. כל ה-JS ב-`defer`.
- `loading="lazy"` + `decoding="async"` בכל תמונה, פרט לתמונת ההירו
  (`eager` + `fetchpriority="high"` — היא ה-LCP).
- `width`/`height` מוטבעים בכל תמונה מצורפת → CLS אפסי.
- כל התמונות בפורמט **WebP** (תמונת ההירו ירדה מ-629KB ל-125KB).
- אין קריאות API בטעינת עמוד; אין שאילתות SQL מעבר למה שהליבה עושה — כל התוכן
  מגיע ממטמון ה-meta של העמוד הנטען.
- `itt_pages` נשמר עם `autoload = false`.

## אבטחה

- Escaping על כל פלט, sanitization על כל קלט לפי סכמת השדות. שדה שאינו בסכמה
  **נזרק** — אי אפשר להבריח מפתחות נוספים ל-meta.
- שמירה בעורך: nonce + `current_user_can( 'edit_post' )`, דילוג על autosave
  ורוויזיות.
- מסך הכלים: nonce + `manage_options`, `wp_safe_redirect`.
- REST: `permission_callback` על שני ה-endpoints, nonce על השליחה,
  rate limiting, honeypot.
- הפניות נשמרות ב-CPT פרטי עם **capabilities ייעודיות** (`itt_leads`) שמוענקות
  לתפקיד המנהל — לא בדיקת role בקוד.
- אין `eval` / `exec` / `base64`, אין SQL ישיר, אין סודות בקוד.

## מה עוד חסר מהלקוח

מהעיצוב עצמו חולצו כל התמונות שהיו קיימות בו. עדיין חסרים:

- **סרטון העדות הראשי** ו-**5 סרטוני ההמלצות** — כרגע מוצגות תמונות הפתיח בלבד.
- **תמונות פתיח להמלצות 4 ו-5** — לא היו בקובץ העיצוב; כרגע חוזרות תמונות 1–3.
- **שמות התלמידות ומשפטי המפתח** בסליידר — טקסט ממלא מקום מהעיצוב.
- שני הציטוטים לסקשן הוידאו, שאמורים להישלף מתוך הסרטון אחרי בחירתו.
- קובצי הגופן Ploni.
- שלושת הסעיפים המסומנים בהצהרת הנגישות.

## הערה על העיצוב

ה-README של חבילת ההנדאוף מתאר את תמונת ההירו כ"מימין", אבל בקוד המקור
ובקובץ ה-standalone (שהוא "הקובץ הקובע" לפי אותו README) הטקסט הוא הפריט
הראשון ב-grid, כלומר **הטקסט מימין והתמונה משמאל**. התבנית עוקבת אחרי הקובץ
הקובע. אם הכוונה הייתה הפוכה — זו החלפה של שתי שורות ב-`itt-landing.css`.
