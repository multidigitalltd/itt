# גופן Ploni

הגופן **Ploni** הוא גופן מסחרי ברישיון, ולכן **אינו מצורף לתבנית**. התבנית מצהירה
עליו ב-`assets/css/itt-base.css` ומצפה למצוא כאן שלושה קבצים:

```
assets/fonts/ploni-regular.woff2    (400)
assets/fonts/ploni-demibold.woff2   (600)
assets/fonts/ploni-bold.woff2       (700)
```

## מה לעשות

1. לוודא מול הלקוח שיש רישיון Web לגופן עבור הדומיין של האתר.
2. להמיר את הקבצים ל-`woff2` (חוסך כ-30% לעומת `woff`) ולהעלות אותם לתיקייה הזו
   בדיוק בשמות שלמעלה.
3. זהו. ה-`@font-face` כבר מוגדר עם `font-display: swap`, ושני המשקלים הנפוצים
   (400 ו-700) נטענים ב-`preload` אוטומטית — אבל **רק אם הקבצים קיימים בפועל**,
   כדי לא לשלוח בקשת 404 בכל טעינת עמוד.

## עד שהקבצים מועלים

התבנית נופלת חזרה ל-`Assistant` / `Heebo` / גופן המערכת. הדף עובד ונראה תקין,
אבל **הקצב הטיפוגרפי שונה מהעיצוב** — שורות נשברות במקומות אחרים והעמוד יוצא
ארוך יותר. אין להשוות pixel-perfect מול קובץ העיצוב לפני העלאת Ploni.

אם אין רישיון ולא יהיה — יש לתאם חלופה מול הלקוח לפני ההטמעה ולעדכן את
`font-family` ב-`itt-base.css`. אין להחליף גופן שרירותית.
