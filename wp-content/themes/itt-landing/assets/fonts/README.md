# גופן Ploni

הגופן שבשימוש הוא **Ploni ML v2 AAA** — אותם קבצים בדיוק שמוטמעים בקובץ העיצוב
(`landing-page-standalone.html`), שחולצו והומרו ל-WOFF2.

```
ploni-regular.woff2   / .woff    (400)
ploni-demibold.woff2  / .woff    (600)
ploni-bold.woff2      / .woff    (700)
```

`@font-face` מוגדר ב-`assets/css/itt-base.css` עם `font-display: swap`, ומעדיף
WOFF2 עם נפילה ל-WOFF בדפדפנים ישנים. שני המשקלים הנפוצים (400 ו-700) נטענים
ב-`preload` אוטומטית מתוך `ITT_Theme::preload_fonts()` — ורק אם הקבצים קיימים
בפועל, כדי לא לשלוח בקשת 404 בכל טעינת עמוד.

**אין מה לעשות — זה כבר עובד.**

## רישוי

Ploni הוא גופן מסחרי. הקבצים כלולים כאן על בסיס הרישיון של בעלי האתר. שני
דברים שכדאי לוודא מול ספק הגופן:

- שהרישיון מכסה **שימוש Web** (לא רק Desktop) — אלה שני רישיונות נפרדים.
- שהוא מכסה את **הדומיין** שאליו האתר עולה, ואת מכסת הצפיות החודשית.

אם הרפוזיטורי הזה הופך ציבורי בשלב כלשהו, יש להוציא את הקבצים ממנו — הפצה
פומבית של קובץ גופן חורגת כמעט מכל רישיון Web.

## החלפה או הוספת משקל

1. להמיר את קובץ המקור ל-WOFF2 (ול-WOFF אם רוצים גיבוי).
2. לשמור כאן בשם `ploni-<משקל>.woff2`.
3. להוסיף בלוק `@font-face` תואם בראש `assets/css/itt-base.css`.
4. אם זה משקל שכדאי לטעון מראש — להוסיף אותו ל-`ITT_Theme::FONT_FILES`
   ולרשימת ה-preload.

## אם מסירים את הקבצים

התבנית נופלת חזרה ל-`Assistant` / `Heebo` / גופן המערכת. הדף עובד ונשאר נגיש,
אבל **הקצב הטיפוגרפי משתנה** — שורות נשברות במקומות אחרים והעמוד יוצא ארוך
יותר בכ-10%. אין להשוות pixel-perfect מול קובץ העיצוב במצב הזה.
