# גופנים

שתי משפחות מקובץ העיצוב, **שתיהן מותקנות**. ברישוי של הלקוח.

| משפחה | תפקיד | קובץ | משקל ב-CSS | usWeightClass |
|---|---|---|---|---|
| **Atlas** | טקסט, ממשק, כפתורים | `atlas-regular.woff2` | 400 | 400 |
| | | `atlas-medium.woff2` | 500 | 500 |
| | | `atlas-bold.woff2` | 600–700 | 700 |
| | | `atlas-black.woff2` | 800–900 | 900 |
| **Gloria** | כותרות, שם המותג, **כל המספרים** | `gloria-regular.woff2` | 400 | 400 |
| | | `gloria-demibold.woff2` | 500–600 | 600 |
| | | `gloria-bold.woff2` | 700–900 | 700 |

שם המשפחה הפנימי: `Atlas DL 3.1 AAA` ו-`Gloria DL v1 AAA`. שתיהן מכילות את
**מלוא הטווח העברי** (52 ו-50 תווים בבלוק `U+0590–U+05FF`, כולל ניקוד) ואת
הלטיני והספרות. אין צורך בגופן נפילה לעברית.

הקבצים סופקו כ-WOFF והומרו ל-WOFF2 ללא שינוי בגליפים
(`fontTools`, `flavor = "woff2"`) — כ-22% קטנים יותר. שלושת הקבצים שמעל הקיפול
(`atlas-regular`, `atlas-black`, `gloria-bold`) הם 121KB יחד ומקבלים `preload`.

## `atlas-light` — מוצהר ולא בשימוש

ב-`msl-app.css` יש הצהרת `@font-face` ל-Atlas במשקל 300, והקובץ לא סופק.
**זה לא גורם ל-404:** אין בגיליון הסגנונות אף כלל שמבקש משקל 300, ולכן הדפדפן
לעולם לא מושך את הקובץ. נבדק — `document.fonts` מדווח על הפנים הזה כ-`unloaded`
ואפס בקשות רשת נכשלות. ההצהרה נשארה כדי שאם הלקוח ישלח את Light בעתיד,
הוספת הקובץ לתיקייה תספיק.

## החלפה או הוספה של קובץ

1. להעתיק WOFF2 לתיקייה הזאת בשם שבטבלה.
2. זהו. הצהרות ה-`@font-face` כבר כתובות ב-`assets/css/msl-app.css`,
   וה-`preload` מודפס **רק לקבצים שקיימים בפועל** (`MSL_Theme::preload_fonts()`).

אם מגיע TTF/OTF/WOFF — להמיר ל-WOFF2 לפני העלאה, לא להגיש ישירות.

## שבירת הכותרת הראשית — נמדד

ברוחב 1440 פיקסלים הכותרת היא 66.24px, והתיבה שלה חסומה ב-`max-inline-size: 660px`.
השורה "כל אחד מוסיף אור קטן." דורשת **930px ב-Gloria** ו-679px בגופן הנפילה —
כלומר **היא נשברת לשתי שורות בשני המקרים**, וגובה ה-`h1` זהה (260px).

גרסה קודמת של הקובץ הזה טענה שב-Gloria השורה נכנסת לשורה אחת. זה לא נכון:
Gloria רחבה מהנפילה, לא צרה ממנה. אם רוצים שורה אחת — צריך להעלות את
`max-inline-size` ל-940px לפחות, וזו החלטת עיצוב, לא באג בגופן.
